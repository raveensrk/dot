# Global instructions

Before doing anything else, read and follow [Common instructions](~/repos/agent1/common.md).

## Where files go

Before creating a file, check [~/dot](~/dot) and the matching repo under `~/repos/` for one that already does the job. Reuse it. Do not add a second copy.

Temporary files go in `~/tmp`. Do not write them under `/tmp` or into a repo.
