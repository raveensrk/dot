# AGENTS

Machine-wide instructions for any agent working under `~`.

Before doing anything else, read and follow [Common instructions](~/repos/agent1/common.md).

Also read:

1. [Repos AGENTS.md](~/repos/AGENTS.md) - tools in `~/repos` that agents can use from any folder.
2. [Dot AGENTS.md](~/dot/AGENTS.md) - tool configs and how they are installed.

## Where files go

Before creating a file, check [Dot](~/dot) and the matching repo under [Repos](~/repos/) for one that already does the job. Reuse it. Do not add a second copy.

Temporary files go in [Home Tmp](~/tmp). Do not write them under [System Tmp](/tmp) or into a repo.
